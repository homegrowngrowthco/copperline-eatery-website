## 3. What this run could not measure, and why

- **Organic rank.** Every organic result came back as `google.com/goto?url=<encrypted>`, so the script's organic column says "absent" everywhere. Google started wrapping result links and DataForSEO does not resolve them. Use the GSC positions in section 1 instead. Fix: match the organic item's title or breadcrumb, not its domain (a TODO line in `../TODO.md`).
- **Review and photo velocity.** The `business_listings/search` database is stale. It returned Copperline at exactly 1,120 reviews and 241 photos, the same as on 09-24, and Sunny Side Up at 925 while the live pack shows 941. The 09-24 velocity table may have used the same stale data. Fix: read the 6 tracked listings live with `business_data/google/my_business_info` (a few cents more per run; same TODO line). For the same reason, this pull cannot re-confirm the `accepts_reservations` attribute.
